# Flowline

**Summary:** Configurable item, fluid, and energy pipes with per-side control, filters, and upgrades.

## Description

Flowline adds item, fluid, energy, and universal pipes to Minecraft. Set each pipe face to insert, extract, or disconnected, then build transport networks that route resources where you need them.

### Features

- **Four pipe types:** item, fluid, energy, and universal. Universal pipes can carry all three resource types.
- **Per-side controls:** sneak and right-click a face with the Flowline Wrench to cycle its mode. Right-click an extracting face with the wrench or an empty hand to open its settings.
- **Routing options:** choose a distribution mode and redstone behavior for each extracting side.
- **Item and fluid filters:** add allow or block rules using resource IDs, tags, and data components. Filter upgrades add more rule slots.
- **Side upgrades:** Speed changes the starting transfer interval, Stack increases the amount moved per operation, and Knozy combines Speed, Stack, and Filter. Each extracting side has six upgrade slots.
- **Adaptive transfers:** active sides speed up, idle sides back off, and sides without targets sleep until the network changes. Network targets are cached between changes.
- **English and Turkish translations.**
