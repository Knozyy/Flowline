# Flowline 1.20.1 → 1.21.1 Özellik Taşıma Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `1.20.1` dalındaki (Forge, mod 0.3.6) bütün özellikleri `1.21.1` dalına (NeoForge 21.1, Java 21) taşımak; sonuçta 1.21.1 jar'ı 1.20.1 ile aynı özellikleri sunar ve aynı 82 GameTest'i üç turda (normal, `-PwithCurvy`, `-PwithMekanism`) geçer.

**Architecture:** İki dal `75f07d3`'te ayrıldı. 1.20.1, `16f1bf1` "Backport" commit'iyle 1.21.1 kodunun Forge'a çevrilmiş hâlidir; sonra 38 özellik commit'i aldı. 1.21.1'in sonradan aldığı 4 commit (`46dd92c 517e55a 7d6e028 435bee8`) 1.20.1'de de birebir var (`e51d14b b0888fb 0715fa7 334a027`). Bu yüzden taşınacak özellik farkı tam olarak `git diff 334a027 1.20.1`'dir. Bu fark 1.21.1 ağacına **3-yollu** uygulanır: özellik satırları NeoForge koduna kendiliğinden oturur, yalnızca API satırlarına değen parçalar ve yeni dosyalar elle çevrilir. Kaynak dosyalar (JSON/PNG) yamalanmaz; Python üreteci 1.21.1 biçimine çevrilip yeniden üretilir.

**Tech Stack:** NeoForge 21.1.172, ModDevGradle 2.0.147, Java 21, Mixin (NeoForge'un yerleşik), JEI 19, EMI 1.1.22, Jade API, Mekanism 10.7.15, TOP/WTHIT (1.21.1 NeoForge sürümleri), Curvy Pipes 1.21.1-1.15.8 (opsiyonel), Patchouli (yalnız veri).

**Spec:** Ayrı spec yok; spec = `1.20.1` dalının HEAD'i (`5250b54`) + `CHANGELOG.md` (0.1.9–0.3.6) + Kovan `30-Hafiza/Projeler/Flowline.md`'deki kullanıcı kararları.
